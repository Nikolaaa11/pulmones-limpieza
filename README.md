# Pulmones: qué funciona, qué daña

Sitio estático (HTML + CSS, sin dependencias) con la investigación forense de medicinas naturales y farmacéuticas para los pulmones. Fondo blanco, estilo Apple.

Información de investigación, no consejo médico. Las cifras vienen de resúmenes de buscadores y deben verificarse contra la fuente primaria.

## Ver en local

Abre `index.html` en el navegador.
